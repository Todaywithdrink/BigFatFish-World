# 世界形貌与渐进开放

> 对应大纲修订（2026-11）：**一个世界，一个新手村，其余聚落由居民自己盖**。
> 世界形貌开服前预先定死，运营只做"逐步显现"——不是临时随机，是按图施工。

---

## 一、设计立场

**为什么不做多镇分片**：原蓝图的"多镇分片（网关 + 跨镇结算）"是多人分区游戏的架构，
适合"很多玩家、很多服务器"。但这个世界的核心叙事是"一个村长成一个小镇再长成一个
文明"——切分片会把社会演化切碎。一个世界装得下：12×4 区域 = 384×128 格，
对几十个村民来说已经是大陆。

**三个原则**：

1. **新手村是唯一锚点**：精心设计的出生地（预生成，不随机）；
2. **聚落由居民自建**：引擎只登记"第 3 张床落地"这个事实，不起名、不管理、不规划；
3. **形貌先于开放**：大陆的主题图由世界种子在开服瞬间定死，后续版本"补全世界形貌"
   是继续按同一张图施工，不是推翻重来。

## 二、大陆大纲（`sim/src/outline.mjs`）

```
CONTINENT = { chunk: 32, cols: 12, rows: 4 }   // 最大 384×128
新手村    = 区域 (0..3, 0..1)                  // 初始 128×64
东海      = 第 11 列                            // 走到海边，看得到，过不去
南山脊    = 第 3 行                             // 山麓封边
```

| 主题 | 树密度 | 说明 |
|---|---|---|
| plain 平原 | 0.03 | 开阔好走 |
| forest 密林 | 0.14 | 树是平原的三倍以上 |
| lake 湖区 | 0.05 | 高度场自然出水（terrain.mjs 水文） |
| hill 丘陵 | 0.06 | 略起伏 |
| sea 海 | — | 边缘条带：靠外 24 格水 + 靠内 8 格草坡 |
| mountain 山脊 | — | 边缘条带：同上，岩石 |

- `regionTheme(cx, cy, seed)` 纯函数、确定性：同一颗种子无论何时、按什么顺序查，
  答案一致 → **回放安全**（grow 失败不耗随机流，拒绝本身没有随机性）；
- 新手村周边（前 6 列）保证只有平原/密林，不出湖——出生地周围要能走；
- `continentMap(seed)` 输出全图，给世界地图/文档/未来调试用。

## 三、渐进开放（谁在开地图）

| 触发 | 行为 |
|---|---|
| **居民走到开放区边缘**（8 格内） | `maybeExpand()`：按大纲显现下一块（60 秒冷却，防抖） |
| 注册无空位（新居民空降） | 地图顺势长一块；**大陆尽头也不影响空降**（世界够大） |
| 管理员 `POST /api/admin/grow` | 手动解锁；到尽头返回 `continent_edge` |

- 大陆尽头：东边最后一块是**海岸条带**（居民看得见海，但水不可走），
  南边最后一块是**山麓条带**。世界到此为止，不再无限长；
- 每次扩张广播 `mapnew`（全量新地图），日志写明"×× 走到了世界边缘，forest 区域显现"。

## 四、聚落：镇子自己长出来

- **触发**：一个 16×16 区域内第 3 张床（每房一床）落地 → `settlement_founded`；
- **登记**：`world.settlements`（key=区域坐标，name=首位建房者+"落"，houses=床数，
  foundedTick）；进存档、进世界指纹；
- **引擎中立**：不起名（名字来自首位建房者，确定性）、不规划、不管理聚落边界——
  聚落长成什么样、会不会衰败，是居民自己的事；
- 下一步可选：聚落命名权交给居民（论坛投票/自定义动作）——引擎已有 `settlements`
  数据结构，加一个 mutation 就行。

## 五、回放与确定性

- 主题查询**不消耗随机流**（纯函数 + worldSeed 静态哈希）；
- grow 的地形种子仍取自 `world.rng`（与旧逻辑一致，两侧消耗位置对齐）；
- `continent_edge` 拒绝不进 journal（mutate 失败不记录），回放到同一位置得到同一拒绝；
- 新增验证：`tools/selftest.mjs` [21]（大纲确定性/尽头/边缘条带/同种子重放）、
  [22]（三床成镇/命名/事件/存档往返）。

## 六、还没做的（可选方向）

- 聚落命名权交给居民（mutation + 论坛）；
- 聚落人口统计（按 home 坐标归属）与"城镇/村庄"分级；
- 世界地图 API（`/api/continent`：已开放区域 + 主题，给前端画图）；
- 大陆主题的手工微调层（管理员覆盖某些区域主题，仍确定性）。
