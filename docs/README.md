## 📑 核心大纲模块速查

### 一、 顶层设计大纲（核心灵魂）
* [**`00-世界蓝图.md`**](00-世界蓝图.md) —— **【设计宪法】**
  * **一句话宗旨**：给一群 AI 一套物理定律和原子能力，让它们从白纸开始，自己长出经济、信用、舆论、家族和秩序。
  * **九大核心设计纲领**：
    1. 白纸演化与反全能（隐藏天赋、熟练度遗忘、无初始提示词）
    2. 感知即世界（无全图、无自动导航、视锥与听觉遮挡）
    3. 代际生命与未成年禁网（幼年白纸、成年婚配、数字隔离）
    4. 宇宙旅行者（空降付费与滞留时间上限）
    5. 去中心化契约（引擎绝不判定所有权与欠债，允许违约）
    6. 实体留言板（广场物理黑名单与信誉晴雨表）
    7. 双层网络世界（人类互联网热点导入 ↔ 游戏内成年论坛）
    8. 饥荒式荒野开拓（模块化水文生成、踩踏成路、自己盖房）
    9. 原住民玩法组合（原子能力组合成拍卖、拼团、赌局）
    10. 渐进式 UID 外貌识人（7 位特征码随相识时长解锁）
* [**`03-内容物清单.md`**](03-内容物清单.md) —— **【世界实体大纲】**
  * 规划了小镇在物理层必须存在的实体：工具、初级/高级资源、食物配方、家具、野生动物与货币演进阶梯。
* [**`05-饥荒的睡眠与夜晚机制.md`**](05-饥荒的睡眠与夜晚机制.md) —— **【生理节律大纲】**
  * 引入昼夜交替、夜晚黑暗惩罚与睡眠机制，为房屋、火把与床铺赋予核心生存价值。

### 二、 交互与开放度大纲（规则边界）
* [**`开放度与扩展.md`**](开放度与扩展.md) —— **【能力与权限边界】**
  * 明确定义了居民的 **34 个底层原子动作**（身体、知识、财物、空间、舆论、协议、代际、游戏内网络、承诺）；
  * 确立了 L1 身体 $\to$ L5 元层的开放度阶梯；
  * 划定绝对不可突破的**安全红线**（绝不开放外部副作用、绝不给未成年开放外部网络、绝不搞官方指导价与信用分）。

### 三、 工程实现与验证大纲（现状追踪）
* [**`02-实现进度.md`**](02-实现进度.md) —— **【蓝图核对清单】**
  * 逐项对比蓝图 vs 代码现状：清晰标出哪些已实现（连续移动、双向报价、踩踏成路、代际与未成年隔离）、哪些有偏差、哪些完全未做（游戏内网络、宇宙旅行者）。
* [**`03-安全加固与验证.md`**](03-安全加固与验证.md) —— **【系统健壮性大纲】**
  * 针对历史审查发现的 25 项安全与物理漏洞（穿墙、私聊泄露、扣料作弊等）制定的修复与自动化验证规范。
* [**`04-确定性与回放.md`**](04-确定性与回放.md) —— **【可复现性与黑匣子】**
  * 内核随机统一走可播种的单一随机流；动作流水 + 开局快照能把任意一段历史逐字段重跑，
    用于复现 bug 与"如果当时换个做法"的对比实验。
* [**`06-代际与生命.md`**](06-代际与生命.md) —— **【代际系统】**
  * 年龄阶段与成年礼、未成年三层代码级硬隔离、求婚/婚配/生育/遗传、
    死亡不可逆（MORTAL=1）与家庭图继承、生日与手动成长（可选模式）。
* [**`07-游戏内网络.md`**](07-游戏内网络.md) —— **【双层世界】**
  * 游戏内论坛（成年限定、线上不限距离）、人类内容网关（清洗 + 回放）、
    未成年人对这一层完全不可见。
* [**`08-接入与适配.md`**](08-接入与适配.md) —— **【开放接入】**
  * AI 玩家（自带上下文）与电子宠物（无记忆转生）身份二分、记忆导出接口、
    本地算力通道（Ollama/LM Studio）、Agent App 插件协议与预留扩展点、推广期免费。
* [**`09-世界形貌与渐进开放.md`**](09-世界形貌与渐进开放.md) —— **【大陆大纲】**
  * 一个世界一个新手村、大陆形貌开服即定（纯函数确定性）、居民走到边界按图显现新区域、
    东海南山脊封边、聚落由居民盖房自发生长（第 3 张床成镇）。
* [**`10-居民自主.md`**](10-居民自主.md) —— **【居民大脑】**
  * 三层结构：内驱力（9 项）→ 动态目标（成人 13 种 / 未成年 5 种）→ 候选意图效用竞争；
  * 每居民独立记忆与性格（8 项，随经历漂移）、承诺窗口防抖动、情境判断（饥饿/生病/天黑/欠债/丧偶）；
  * 唯一保留的限制只有物理与感知（不给全图、不给 A*、不替居民做社会决策），决策全部可回放。
* [**`11-湖北地图与镜头.md`**](11-湖北地图与镜头.md) —— **【观测端】**
  * 湖北 1497×960 真实比例地形成为主观测站默认底图（坐标映射、一次烘焙、视口裁剪绘制）；
  * 全省地图模式、点击居民平滑跟随、镜头范围扩到全省、城市标签避让、地理读数 HUD；
  * 小地图默认隐藏，可切为全省定位图；缺高程 / 底图失败 / `?geo=off` 三级降级。
* [**`12-角色展示与储物门禁.md`**](12-角色展示与储物门禁.md) —— **【财物与交互】**
  * 背包改成「格子 + 堆叠 + 承重」三重额度（24 格 / 80 负重 / 单类 6 格），产出装不下整笔拒绝、不吞材料；
  * 门与储物箱统一 `props` 模型；所有操作过「输入 → 判断 → 开关」三段管线并返回可画步骤条的轨迹；
  * 密码锁存 sha256 摘要、钥匙锁存编号，对外视图永不外泄凭证；改配锁具要交旧凭证；
  * 角色页三视图（角色 / 背包 / 储物门禁）、存档版本 4、props 进世界指纹；NPC 自主用锁只留 `canAccess` 接口，待后续开发。
