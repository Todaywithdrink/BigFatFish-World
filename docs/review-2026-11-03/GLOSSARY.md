# 大肥鱼世界：审查建议术语

这份词汇表用于本次架构审查，作为后续设计讨论的建议用语，尚不代表项目已采用。

## Language

**世界事实**：世界中实际发生过的事情，以及物体、身体和资源的实际状态；居民可能不知道或误解它。
_Avoid_: 所有人知道的事

**角色认知**：一名居民通过亲见、听闻和推断形成的认识，允许过时、错误或互相矛盾。
_Avoid_: 世界事实、全局记忆

**社会主张**：居民对归属、承诺、债务或关系提出的说法；它可以被相信、争议或拒绝。
_Avoid_: 系统裁决、官方信用

**实验观察者**：为了分析世界而查看运行证据的人，不属于居民的认知来源。
_Avoid_: 普通居民、村长角色

**居民控制者**：为居民选择行动的决策主体；控制方式不改变该居民应遵守的物理规则。
_Avoid_: 居民本身、物理引擎

**受控原住民**：其世界经历只经实验允许的渠道获得的本地居民；不意味着其语言模型没有预训练知识。
_Avoid_: 白纸模型、零先验智能

**外来居民**：可能携带外部知识、外部记忆或外部控制者的居民，应与受控原住民分别分析。
_Avoid_: 纯本土演化样本

**倒地**：居民暂时不能行动、仍有恢复可能的身体状态。
_Avoid_: 死亡

**死亡**：居民生命过程终止；恢复实验备份不属于居民在世界中的复活能力。
_Avoid_: 倒地、短暂停机

**实验分支**：从某个历史状态另行继续的世界，其后续经历与原世界分别保留。
_Avoid_: 偷改历史、居民复活
