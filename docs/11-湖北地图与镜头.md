# 11 · 湖北地图接入与镜头（2026-11-05）

主观测站 `/` 原先只画 `data/world-map.json`（384×96 聚落格），
湖北省 1497×960 的真实比例地形只存在于独立页 `/viewer/world.html`。
本轮把湖北地形**接入主观测站并成为默认底图**，同时重做镜头与小地图。

> 原则：**只换看世界的方式，不改世界本身**。内核仍跑 384×96 聚落网格，
> 居民坐标、存档、世界指纹、SSE 协议一律不动；湖北是视觉/地理映射层。

---

## 一、数据与坐标契约

| 文件 | 内容 |
|---|---|
| `sim/maps/hubei.json` | 1497×960 格，0.5 km/格；阿里云 DataV 行政边界；17 个城市锚点、投影参数、`elevFile` |
| `sim/maps/hubei.bin` | 1 字节/格群系：0 省界外 / 1 湖泊 / 2 江河 / 3 平原 / 4 林地 / 5 山地 / 6 高山 / 7 雪线 |
| `sim/maps/hubei.elev.bin` | 1 字节/格高程，12 m/单位（最大 2791 m） |
| `sim/viewer/geo-layer.js` | 接入层：加载、烘焙、绘制、地理读数、全省定位图 |

坐标映射（`geo-layer.js` 顶部常量，纯前端，内核无感）：

```
1 世界格 = STEP(2) 湖北格 = 1 km
世界 (0,0)      → 湖北格 (700, 500)
聚落中心 (192,48) → 湖北格 (1084, 596)   江汉平原—武汉一带
默认镜头 (32,36) → 湖北格 (764, 572)   30.74°N 112.33°E，距荆门 36 km，海拔 72 m
湖北省全图      → 世界范围 x −350…398.5、y −250…230
```

## 二、渲染管线

1. **一次烘焙**：加载后把 1497×960 格烘焙成 2994×1920 全省缩略图（2 px/格）。
   着色用连续高程过渡（草绿→林绿→岩灰）+ 西北光源山体阴影 + 逐格散列噪声，
   子像素轻抖动避免放大后读成纯色大方块。
2. **每帧一次 `drawImage`**：只取**视口覆盖的湖北格**做源矩形裁剪。
   整图直绘在 3.4× 时目标宽会到 8 万 px（超 Chromium canvas 32767 上限）；
   裁剪后实测 `dw=1632, dh=1088`，与缩放档无关。
3. **图层顺序**：湖北地形（底）→ 聚落人造物 / 路 / 水 / 树 → 居民 → 文字层。
   纯草皮格不再绘制，让湖北地形透出来；房子、路、水、树仍按聚落格叠加。
4. **低倍精简**：`TILE*zoom < 10` 时完全跳过逐格村庄绘制，改画居民标记圆点，
   避免全省视角下几千个 `fillRect`。

## 三、镜头

| 能力 | 行为 |
|---|---|
| 活动范围 | `clampCamera()` 从 384×96 扩到整个湖北省；居民走到聚落边缘也能真正居中 |
| 点击居民 | `selectVillager()` → 选中 + 开启跟随 + 镜头以他为中心；从全省点标记会 560 ms 平滑飞回并放大到 1.35× |
| 平滑过渡 | `viewTween`（smoothstep）同时插值 zoom / x / y；拖动、滚轮、缩放按钮会取消过渡 |
| 全省地图 | 按钮「全省地图」/ `M` / `?overview=1`；zoom≈0.056（1440×900），显示全省、17 城名（带标签避让）、聚落虚线框、居民标记点 |
| 回到居民 | 按钮「回到居民」/ 再按 `M` / `Esc` / 点击居民标记 |
| 地理读数 | 左下角实时显示地形、海拔、最近城市距离、经纬度、当前视野宽度（260 ms 节流） |
| 缩放范围 | 下限由 `geo.minZoom()` 按窗口算（能装下全省），上限 3.4× |

## 四、小地图

- **默认不显示**：`#minimap-wrap.mm-hidden`，`geo=off` 之外的所有模式都隐藏。
- `N` / 「小地图」按钮切换。打开时不是原来的村庄缩略图，而是 **176×120 湖北省定位图**：
  全省地形 + 黄色聚落框 + 白色当前视口框 + 居民点。
- 点击定位图任意位置可把镜头移到对应湖北格（`miniToWorld`）。
- 打开时地理读数条自动上移 192 px，不与定位图重叠。

## 五、三级降级（新用户/旧部署都不会白屏）

| 情况 | 结果 |
|---|---|
| `?geo=off` | 完全退回原 384×96 村庄地图与旧小地图 |
| `hubei.elev.bin` 缺失（早期版本只有 `hubei.bin`） | 高程**可选**；退回 8 色群系地形（省界/江河/山地仍可辨），海拔显示 `—`，不退回旧地图 |
| `hubei.json` / `hubei.bin` 缺失或加载失败 | 自动不接管底图，观测站照常显示聚落，控制台留一行 `[geo]` 说明 |

> 早期版本的 `hubei.json` 没有 `elevFile`、`hubei.bin` 也缺高程，
> 因此加载器内置了上表的三级降级，旧数据不会导致白屏。

## 六、换成自己的服务器时

服务端 `/maps/` 与 `/viewer/` 静态路由、`/api/world`、`/api/stream` 协议**都不需要改**。
只需把 `sim/maps/` 与 `sim/viewer/` 的静态资源同步到你自己的服务目录：

```bash
# 路径按你自己的部署环境填写
cp -r sim/maps/   /path/to/your/world/sim/maps/
cp -r sim/viewer/ /path/to/your/world/sim/viewer/
```

涉及的文件：`sim/viewer/{geo-layer.js, viewer.js, index.html, style.css}` +
`sim/maps/{hubei.json, hubei.bin, hubei.elev.bin}`。

## 七、URL 参数与快捷键

| 参数 / 键 | 作用 |
|---|---|
| `?overview=1` | 启动即全省地图 |
| `?geo=off` | 关掉湖北底图（前后对比） |
| `?mini=1` | 启动时打开定位图 |
| `?follow=1` | 启动即跟随首个居民 |
| `?zoom=`/`?cam=` | 沿用原有初始镜头参数 |
| `M` / `N` / `F` / `V` / `Esc` | 全省 / 定位图 / 跟随 / 视野锥 / 返回 |
| 滚轮 / 拖动 / 点击 | 缩放 / 平移 / 选中并跟随 |

## 九、已知边界

- 湖北是**视觉/地理底图**，不是新的可玩网格：居民仍在 384×96 聚落里活动，
  省界外的地形可看不可达。要让居民真的走出聚落，需要另做内核侧的大陆展开。
- 高倍（>2×）是缩略图最近邻放大，呈像素方块感；这是刻意的像素风，不是加载失败。
- `/viewer/world.html`（Pixi v8 分块观测器）保留，可用来对照更细腻的分层烘焙效果。
- 城市标签在极小窗口下会按距离自动略过，避免叠成一团。
