# 居民自主：没有外部 AI 时，谁在替他们想

> 蓝图第 1.3 条说得很清楚：**引擎不替 AI 思考**。
> 但世界大部分时间并没有外部 AI 接管——这些居民如果只会"饿了吃、闲了逛"的固定脚本，
> 那所谓"白纸演化"就只是一句口号。
>
> 这份文档描述的是第三条路：给本地居民一套**目标驱动的决策机制**，
> 它不预设剧本，只给内驱力、记忆和性格；具体去哪、做什么，由当下处境算出来。

最后更新：2026-11-05

---

## 1. 三层结构：想什么 / 怎么想 / 做什么

```
        ┌─────────────────────────────────────────────┐
        │ 感知  perceive()                            │
        │ 只扫 v.explored 里的格子 → 记成"去过的地方"  │
        └───────────────────┬─────────────────────────┘
                            ↓
        ┌─────────────────────────────────────────────┐
        │ 决策  sim/agents/autonomy.mjs                │
        │ 内驱力 → 目标 → 候选行动 → 效用打分 → 选一个  │
        └───────────────────┬─────────────────────────┘
                            ↓
        ┌─────────────────────────────────────────────┐
        │ 执行  sim/agents/brain.mjs                   │
        │ 只做 translate：走到哪、按什么、跟谁说         │
        │ 所有副作用一律走 world.applyAction            │
        └─────────────────────────────────────────────┘
```

关键约束：**决策层不碰世界**。它返回的是"意图"（goto / act / talk / build / give），
执行层再翻译成内核动作。这样外部 AI 和本地居民用的是同一套原子能力，
本地脚本没有任何特权（不知道的地方照样不知道，够不着的东西照样够不着）。

## 2. 内驱力：不是需求条，是被处境和性格一起挤出来的压力

每想一次，先算 9 个 0~1 的驱力：

| 驱力 | 由什么挤出来 | 性格怎么改 |
|---|---|---|
| `survival` | 饥饿越低越强；背包没吃的额外加压 | — |
| `safety` | 血量、夜里没床 | 谨慎的人更敏感 |
| `belonging` | 距上次说话的时间 | 越外向增长越快 |
| `wealth` | 距离"我想要的钱"还差多少 | 野心放大目标额 |
| `mastery` | 技能平均等级越低越强 | 勤快放大 |
| `curiosity` | 距上次走到新地方的时间 | 好奇放大 |
| `duty` | 未了结的约定条数 | 重规矩的人更在意 |
| `order` | 有没有自己的房子 | — |
| `ambition` | 没房时的成家压力 | 野心放大 |

驱力不是直接指令，它只影响目标的紧迫度。真正决定动作的是下一层。

## 3. 动态目标：从处境里长出来，最多同时 4 个

目标不是排好的队列，是一组**评估函数**。每个函数看处境，返回一个 0~1.4 的紧迫度；
超过阈值的进入活跃目标集，最多 4 个，满了就顶掉最弱的（要高出 0.12 才算"更急"，防抖）。

成人目标（13 种）：

| 目标 | 什么时候冒出来 | 典型计划 |
|---|---|---|
| `rest` 歇一歇 | 精力低 / 夜里 | 回家 → 上床 → 睡；没床就地睡 |
| `eat` 吃口东西 | 有吃的且饿了 | 去认识的灶台 → 吃 |
| `get_food` 弄点吃的 | 没吃的且开始饿 | 去水边钓鱼；有鱼有灶就炖一锅 |
| `hearth` 垒个灶 | 没见过灶台 | 砍树 → 做木板 → 就地垒灶 |
| `debt` 了结旧账 | 有钱还 / 有人欠我 | 还钱；或找到欠账的人当面提 |
| `shelter` 盖自己的房子 | 成年、没房、有野心 | 备料（砍树/做木板）→ 找 5×4 空地 → 盖 |
| `work` 挣点钱 | 钱不够 | 卖富余 → 开拍卖 → 钓鱼/砍树 |
| `social` 找人说话 | 太久没说话 | 走近 → 说一句（走桥接层模型） |
| `explore` 去没去过的地方 | 太久没走到新地方 | 朝"走过最少"的方向走 8 格 |
| `practice` 练手艺 | 技能还生 | 去水边/树边/灶台重复练 |
| `beautify` 收拾家门口 | 有房、有材料、爱整齐 | 种花 / 摆长椅 |
| `civic` 看看告示 | 很久没看论坛 | 去公告板 → 读论坛 |
| `visit` 去看看别的聚落 | 听说过聚落、好奇 | 走到聚落中心转一圈 |
| `care` 照看孩子 | 自家孩子饿了、手里有吃的 | 走过去 → 给一条鱼 |

未成年人另一套（`CHILD_RULES`）：`rest` / `eat` / `follow`（跟着家里人）/ `play`（家附近跑）/ `listen`（凑近听大人）。
**不是"简化版大人"**：他们没有经济目标，蓝图 3.2 的行为面就是"在形成认知，不参与经济"。

目标会过期（ttl）、会因为连续 3 次做不成而放弃并冷静 15 分钟（`mem.cool`）。
放弃时会写一条经验（`mem.notes`），下次不再一头撞上去。

## 4. 情境判断：所有目标一起提案，效用最高的赢

每个活跃目标会提出 0~3 个"此刻能做什么"的候选，带一个 0~1 的 `fit`；
全局打分：

```
score = 目标紧迫度 × (0.35 + 0.65×fit)
        × 性格偏好（外向更愿意走动，勤快更愿意动手）
        − 距离代价（最多 0.18）
        − 冒险代价（谨慎 × 是否盲目走）
        + 0.03 以内的个人随机
```

这意味着：

- **目标之间会互相竞争**，不是一条 if-else 链。饿着的人和想社交的人，选出来的动作不一样。
- **同一目标在不同处境下给不同动作**：`get_food` 有灶有鱼就做饭，有水就钓鱼，什么都没有就出去找。
- **不会一秒一换**：一旦决定去 5 格以外的地方，会先走 50 tick（`commit`），
  除非出现真正的急事（快饿死、快没力气、重伤）。没有这个窗口，人会在两个分数接近的念头之间原地横跳。
- **一点自己的主意**：最后的 ±0.03 随机来自居民自己的随机流，避免全村像一个人。

## 5. 记忆：只记自己见过的东西

| 记忆 | 内容 | 用途 |
|---|---|---|
| `places` | 水/树/花/灶/床/公告板/长椅，最多各 14 处 | 决定往哪走。**只从 `v.explored` 里来**，没见过的坐标等于不存在；走近了发现树没了会自动删掉 |
| `outcomes` | 钓鱼/做饭的尝试与成功次数 | 用 Laplace 平滑估成功率，手生的人不会盲目自信 |
| `people` | 说过几次话、被谁打过 | 谨慎高的人会绕开打过自己的人 |
| `seenSettlements` | 听说过/见过的聚落 | 触发 `visit` |
| `notes` | 最近吃过的亏（"材料不够"、"那块地不能用"） | 调试可见，也避免重复踩坑 |

没有全图、没有"最近的水在哪"这种查询。想要知道，只能走过去看。

## 6. 性格会变：经历改人，不是人设常量

初始性格 = 演员表给的三项（乐观/外向/重规矩）+ 从 uid 派生的另外五项
（好奇、勤快、谨慎、大方、野心）。不预设"好人坏人"，只给一个起点。

之后每次经历都会推动一点：

| 经历 | 变化 |
|---|---|
| 钓到鱼 | 勤快 +0.04，乐观 +0.05 |
| 饿到 0 | 谨慎 +0.22，勤快 +0.1，乐观 −0.12 |
| 被打 | 谨慎 +0.35，乐观 −0.25，外向 −0.1 |
| 盖成房 | 乐观 +0.18，重规矩 +0.15，野心 +0.1 |
| 还清账 | 重规矩 +0.08，乐观 +0.08 |
| 送人东西 | 大方 +0.08 |
| 计划连续失败 | 谨慎 +0.02 |

范围锁在 `[0,10]`，并同步回 `v.personality`（乐观/社交/礼貌），
所以桥接层写台词、交易估值读到的都是"现在的他"。

五游戏日四个人的实测（`node tools/autonomy-probe.mjs 5 4`）：性格漂移合计 6.1
（约每人每项 0.1~0.3），不是随机噪声，而是"谁过得顺、谁吃过亏"的痕迹。

## 7. 只在必要时限制

| 限制 | 理由 | 位置 |
|---|---|---|
| 未成年人无经济目标 | 蓝图 3.2 代码级隔离，不靠模型自律 | `CHILD_RULES` + 内核 `isMinor` 兜底 |
| 被外部 AI 接管时不插手 | 一个身体不能有两个大脑 | `Mind.update` 首行 |
| 倒下/死亡不决策 | 物理事实 | 同上 |
| 不知道的地方不去 | 没有全图接口 | `perceive` 只看 `explored` |
| 够不着的东西不做 | 内核距离检查 | `applyAction` |
| 不判定所有权、不仲裁纠纷 | 蓝图第 11 条红线 | 自主层完全不碰 |

除此之外不设限：可以在半夜去钓鱼，可以连着三天盖房，可以把钱全给邻居，
也可以什么都不干——只要目标集里确实没有更急的事。

## 8. 可观测：他此刻在想什么

- `GET /api/minds`：每个人的心情、当前念头、活跃目标及紧迫度、八项性格、
  记住的地方数量、成功率、最近吃过的亏。
- `/api/world` 与 `/api/villagers/:id` 的 `mood` / `goal` 字段：前端可以直接在头顶显示。
- 事件 `new_goal`：目标切换时广播（同一个目标 30 秒内只报一次），观察者能看到
  "老鲤 决定：垒个灶"。
- 调试：`BRAIN_DEBUG=1` 会把每次决策异常打到日志（默认吞掉，避免刷屏）。

---

## 9. 可回放：自主不等于不可复现

- 决策层用**自己的随机流**（由 uid 派生），不碰 `world.rng`。
  每秒想一次不会把内核的随机序列搅乱。
- 决策节奏挂在 `world.tickCount` 上，不挂墙钟：同种子 + 同 tick 驱动 = 同样的选择。
  `selftest [23]` 里两台同种子世界跑 4000 tick 后指纹一致。
- 心境（目标/记忆/性格）单独存 `data/minds.json`，**不进世界指纹、不进动作流水**。
  回放的是"做了什么"，不是"想过什么"；读档时把心装回去，人接着过自己的日子。
- `tools/autonomy-probe.mjs`：5 游戏日 × 4 人，检查
  "没人饿死 / 有人自己吃上饭 / 有人走出家门 / 目标≥5 种 / 性格有漂移 /
  有人自己盖房 / 需求无 NaN / 同种子双跑一致"。

## 10. 顺带修掉的地基问题

自主性一上线，几个一直藏着的问题立刻暴露了（都不是"AI 不聪明"，是地在漏）：

1. **休息永远醒不来**：`stepEntity` 先把精力补到 100，同一 tick 又被 `decayNeeds`
   扣成 99.99，`>= 100` 的起床条件永远不成立。结果全村躺平不吃不喝。
   → 先判"睡饱"再结算消耗。
2. **看不见树和墙**：`lineBlocked` 采样到了终点格自己，不透明的树/墙永远进不了
   `explored`，居民不知道世界上有树。→ 终点格不参与遮挡。
3. **房子盖在自己头上**：`buildHouse` 不检查建造者站位，墙一围就把人封死。
   → 落成后把人挪到门口；另加 `unstuck()` 兜底（脚下不是可走格就挪到最近落脚点）。
4. **灶台根本不存在**：地图里 0 个 stove，`eat`/`cook` 全部不可达。
   → 世界生成在广场边放一口公共灶台（`World({hearth:true})`），
   同时把 `stove` 加入可建造清单（木 4 + 木板 1），居民可以自己再垒。
5. **走出房间是局部死胡同**：贪心走法在 3×2 的屋里会沿墙南北横跳。
   → `tryExitRoom()`：在室内时先找门、开门、迈出去，再谈目的地；
   另有"14 步内只在 3 格打转"的绕路检测。
6. **存档丢了半截路**：`path` 没进存档，读档时正在走的人凭空停下，世界线分叉。
   → `path` 入档，`determinism` 的存档往返改走真实 `serializeWorld/loadSave`。

## 11. 已知边界（明确不做）

- 不替居民做社会决策：不判定谁对谁错、不分配资源、不强制履约。
- 不做全局寻路：只有"先出门"和"撞了就绕"，没有 A*。
- 不做完美记忆：地点会过期、会因验证失败被删；成功率是估计不是事实。
- 不保证活得好：这套机制只保证"他自己在选"，不保证选对。
  一个谨慎又悲观的人可能守着空房子饿肚子——那是他的性格，不是 bug。
