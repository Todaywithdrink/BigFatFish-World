## 一、改了什么

### 1. 新增 `sim/src/netguard.mjs`（统一边界）

一个模块管住"进"和"出"两个方向，避免限制散落在各个路由里：

| 导出 | 作用 |
|---|---|
| `checkModelBaseUrl(url, {allowHosts, allowPrivate})` | 出站端点校验：只放行 https、禁私网/回环/链路本地/云元数据、可配白名单 |
| `allowedModelHosts()` / `allowPrivateModel()` | 从 `AVB_ALLOWED_MODEL_HOSTS` / `AVB_ALLOW_PRIVATE_MODEL=1` 读配置 |
| `readJsonBody(req, limit)` | 带上限的 JSON 读取；超限返回 `{tooLarge}` 而**不 destroy socket**（否则客户端只看到 hang up） |
| `makeCorsChecker(port)` | 默认只回显自己人的 Origin，`AVB_CORS=*` 才全放开 |
| `publicUpstreamError(status)` | 上游错误只给状态码，不回显响应体 |

### 2. `sim/server.mjs`

- `HOST` 默认改回 `127.0.0.1`（原来默认 `::`，等于全网卡监听）。
- CORS 从无条件 `*` 改为按 Origin 白名单回显，`OPTIONS` 跟着改。
- 所有 `/api/agents/*` 也进限流（之前整段被排除）；`register` 改成先读 body 前就限流。
- 动作冷却从"读 body 前判断、读完后赋值"改成**读完 body 再原子判断并占位**，并发打不穿。
- body 上限 256KB（`AVB_MAX_BODY`），超限返回 413 并排空剩余包。
- token 支持 `Authorization: Bearer` / `X-Agent-Token`，URL 里的 token 仍然兼容但不再是唯一方式。
- token 加了 90 天有效期（`AGENT_TTL_DAYS`）。
- **托管 agent 闲置回收**：按"最近一次成功行动"算，3 天没成功就释放村民、删掉绑定
  （`AGENT_IDLE_DAYS`）——原来 hosted 被显式排除在清理循环外，一个邀请码等于永久占位。
- 所有对外出口统一走 `pubFor(v, observer)` / `redactEvent(ev, observer)`，不再直接 `pub()`。

### 3. `sim/src/world.mjs`（投影收口）

- 新增 `pubFor(v, observer)`：私聊气泡只对本人可见，其余人拿到 `{text:null, hidden:true}`。
- 新增 `redactEvent(ev, observer)`：`utterance` / `said` 的正文按当事人判定是否脱敏。
- `snapshot(observer)` 的实体、日志都走投影；`/api/world`、`/api/log`、SSE 广播全部接上。
- 事件体内的投影也改成带观察者版本：`noticed_approach.who`、`saw_fall.who`、`utterance.from`。
- `heard_muffled` 不再携带 `pub(v)`（原来"听不清"的事件里夹着完整 `bubble.text`）。
- `face` 动作的角度做了取模归一（原来可以传任意数值）。
- `actBuild` 里重复的冷却检查删掉一处。
- 新增 `CFG.ROAD_SPEED = 1.35`：走在 `path` 地块上移速加成。

### 4. `sim/agents/hosted.mjs`

- 每次出站前三步校验（注册时、存盘后、调用前都校验），存档里的旧配置也绕不过。
- 上游响应体只进服务端日志，`stats.lastError` 只保留归类后的短语。
- 连续失败指数退避（5s → 10min 封顶），坏 key 不会每 5 秒打一次。

### 5. `bridge/server.mjs`

- Origin 校验：浏览器带来的 Origin 必须是本机同端口，否则 403（挡 CSRF：`text/plain` 简单请求也带 Origin）。
- Host 校验：监听在回环上时 Host 必须是回环（挡 DNS rebinding）。
- body 上限 32KB，超限 413。
- `field()` 净化：名字/地点/关系/上一句等外部可控字符串，去控制符、换行、模板符号再进提示词
  （原来 `npcDisplayName` 原样拼进 system prompt，联机时改个名就能改写所有村民行为）。
- 上游模型错误不再把响应体回显给调用方。

### 6. `mods/AiVillagers`（C#）

- 新增 `DialogueText.Sanitize()`：去掉 `$ % # @ { } ^ ~ | ` 这些星露谷对话控制符、换行、控制字符，
  超长在标点处截断。
- `Apply()` 缓存和 `DrawDialogue()` 前都过一遍；净化后为空就退回"……"。

### 7. 功能推进

- `sim/agents/brain.mjs`：**本地 NPC 不再用 `findPath`**。
  - `stepToward()`：先走差值大的轴，撞了换轴，再沿墙绕；撞过的方向下次排最后。
  - `pickWander()`：目标只从 `explored` 里挑，没探索过的地方等于不存在。
  - `maybePave()`：走通一步后有概率把脚下草地踩成 `path`。
  - 灶台也只去"见过"的那一个。
- `sim/tools/selftest.mjs`：过时的"摔落伤害"用例换成"高差挡路"的**真实不变量**，
  私聊用例补了 4 条泄露断言（事件体/观众快照/观众日志/本人可见）。
- 新增 `sim/tools/brain-probe.mjs`、`bridge/tools/smoke.mjs`。

## 二、验证

全部在本机跑，**用临时副本**（`$TEMP/simtest2`、`$TEMP/bridgetest`），没有碰正式存档。

| 项 | 命令 | 结果 |
|---|---|---|
| 内核自测 | `node sim/tools/selftest.mjs` | **21 passed / 0 failed**（原 14/2） |
| HTTP 边界 | `node $TEMP/smoke2.mjs` | **18 passed / 0 failed** |
| bridge 边界 | `node bridge/tools/smoke.mjs` | **7 passed / 0 failed** |
| NPC 行为 | `node sim/tools/brain-probe.mjs 180` | 位移 10.8 格、踩出 1 格土路、无卡死 |
| 模组编译 | `dotnet build` | **0 warning / 0 error** |

HTTP 冒烟覆盖：健康检查、跨源 Origin 无 ACAO、同源回显、300KB→413、
云元数据/本机/明文 http 三类端点被拒、注册→观测→动作、冷却期并发 4 发全 429、
错误 token→401、观众快照无天赋、管理接口无密钥 401、路径穿越 404。

bridge 冒烟覆盖：无 Origin 正常 200、跨站 Origin 403、同源 200、伪造 Host 403、
200KB→413、带换行与指令的名字进不来。

## 三、还没做

1. **确定性 tick**：`Math.random` / `new Date()` 仍在世界内核里，同一存档跑两遍结果不同，
   回放和对比仍然做不了。这是架构层面最大的欠账。
2. **World 拆分**：`world.mjs` 仍然是一个千行大类，动作校验各写各的 clamp。
   建议先把"动作定义 + 参数校验"抽成表驱动，再拆经济/感知。
3. **观测端限流**：SSE 连接数没有上限，`/api/stream` 仍是每连接一份快照。
4. **审计回放**：日志有了，但没有按 tick 回滚/重放。
5. **文档索引**：`docs/02-实现进度.md` 的"动作 27 个"等统计仍靠手写，容易再次失真。

## 四、环境变量速查（新增）

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 想局域网访问再改 |
| `AVB_MAX_BODY` | `262144` | JSON 请求体上限 |
| `AVB_ALLOWED_MODEL_HOSTS` | 空 | 托管模式额外放行的域名，逗号分隔 |
| `AVB_ALLOW_PRIVATE_MODEL` | `0` | 设为 1 才允许私网/本机端点（自建 Ollama 时用） |
| `AVB_CORS` | 空 | 设为 `*` 才全放开跨源 |
| `AGENT_TTL_DAYS` | `90` | token 有效期 |
| `AGENT_IDLE_DAYS` | `3` | 托管 agent 多久没有成功行动就回收 |
| `AVB_BRIDGE_MAX_BODY` | `32768` | bridge 请求体上限 |
