# 饥荒（Don't Starve Together）的睡眠与夜晚机制

> 来源：本机安装的游戏本体，脚本从 data/databundles/scripts.zip 解包，路径与常量都能在源码里核对。
> 提取出来的文件放在 docs/dst/（sanity.lua、sleepingbag.lua、tent.lua、bedroll.lua、tuning.lua）。

## 一、睡觉：不是“回血”，是“用饥饿换血和理智”

睡觉逻辑在 components/sleepingbag.lua，按秒跳一次（SLEEP_TICK_PERIOD = 1），每次跳三个值（tuning.lua）：

    SLEEP_HEALTH_PER_TICK = 1      -- 每秒 +1 血
    SLEEP_SANITY_PER_TICK = 1      -- 每秒 +1 理智
    SLEEP_HUNGER_PER_TICK = -1     -- 每秒 -1 饥饿

不同床的倍率：

| 床 | 回血 | 回理智 | 备注 |
|---|---|---|---|
| 帐篷 tent | ×2（+2/s） | ×1 | 耐久有限，可白天睡 |
| 睡袋 bedroll | ×0.5 | ×2/3 | 一次性的 |
| 草席 straw roll | 同睡袋 | 同睡袋 | — |

**关键：睡觉是“付费恢复”。** 一个夜晚按 4 分钟算，睡过去要吃掉 240 点饥饿——
是拿今天的饭换明天的命，不是免费的休息。

## 二、夜晚：掉的是理智，不是血；而且光能抵消

sanity.lua 按身边的光照分三档：

    SANITY_HIGH_LIGHT = 0.6      -- 亮：不掉
    SANITY_LOW_LIGHT  = 0.1      -- 灰：慢掉
    SANITY_NIGHT_LIGHT = -100/(night_time*20)
    SANITY_NIGHT_MID   = -100/(night_time*20)
    SANITY_NIGHT_DARK  = -100/(night_time*2)   -- 全黑：掉得最快

也就是说：

- 站在篝火/火把旁边 → 不掉理智
- 站在灰暗处 → 掉得慢
- **全黑** → 掉得飞快，而且黑暗里还有查理

**光 = 安全的锚点。** 夜的惩罚不是“你在外面就掉血”，而是“你没光就崩溃”。

## 三、和我们现在做的对比

| | 饥荒 | 我们（现状） |
|---|---|---|
| 睡觉恢复 | 血 + 理智，按秒 | 血 + 精力，按秒 |
| 睡觉代价 | **扣饥饿** | **免费** |
| 夜晚惩罚 | 黑暗掉理智，**光能挡** | 室外掉精力，**光不能挡** |
| 睡觉时机 | 主要夜里；帐篷可白天 | 任何时候 |
| 床的归属 | 无（谁都能用） | 无（一致） |

## 四、建议改法（照饥荒的骨架，换我们的数值）

1. **睡觉扣饥饿**：床每秒 -0.12 饥饿，睡一晚掉 20 左右
2. **夜晚按光分档**：
   - 身边有路灯/火（半径内）→ 不掉精力
   - 没光 → 掉精力、不回血
3. **白天睡觉只回精力、不回血**，逼出“晚上才睡”的节奏
4. 床仍然公共，谁抢到谁睡

这样“夜里没光 → 崩溃 → 抢床/造灯”就形成完整的压力链，而不是单纯的数值惩罚。
