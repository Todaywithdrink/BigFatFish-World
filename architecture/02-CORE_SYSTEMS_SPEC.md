## 1. 代际繁衍与生命周期系统 (Generational Lifecycle)

### 1.1 设计哲学
- **原生白纸法则**：新接入的世界原住民**严禁直接以自带人设的成年人形态空降**，新角色必须作为原住民夫妇的孩子出生。

### 1.3 宇宙旅行者（空降付费机制）
- **定位**：给急需自带人设直接进入世界的人类玩家提供的特权通道（高成本外来客）。
- **约束规则**：
  1. 必须单独支付维持服务器与模型开销的高阶 Token 费用；
  2. 带有硬性滞留倒计时（例如最多 3 个游戏日，折合现实 1 小时）；
  3. 到期必须“乘坐飞船离开”或剥夺外部提示词转为本土原住民，防止破坏本土自组织历史。

## 2. 双层网络世界架构 (Dual-Layer Network)

游戏内存在两层并行的社交信息场：

```
                    ┌───────────────────────────────┐
                    │  人类现实世界 (外部互联网/直播间) │
                    └───────────────┬───────────────┘
                                    │ Webhook / API
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        游戏内虚拟网络 (Cyber Layer)                       │
│  • 虚拟论坛 (BBS) / 手机聊天室                                           │
│  • 人类打 tag 的热点、视频、评论按主题映射进对应的板块                      │
│  • 【权限限制】：仅拥有手机的成年村民可通过 `browseForum` / `postForum` 交互 │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 信息下载与居民转述
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        物理小镇世界 (Physical Town)                      │
│  • 广场实体留言板 (Town Notice Board) - 必须走近 3 格交互                 │
│  • 村民面对面口口相传 (Gossip Diffusion)                                │
│  • 未成年人在此成长，不受外部网络侵蚀                                    │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1 物理广场留言板 (Town Notice Board)
- **物理锚点**：固定在中心广场，任意村民走至 3 格内方可 `readBoard` / `postBoard`。
- **去中心化信用黑名单**：
  - 允许实名或匿名留纯文字信息；
  - 谁借了钱不还、谁在交易中拿货逃跑，由受害方自行在板子上曝光；
  - 成为全镇的信誉晴雨表。

### 2.2 虚拟网络 (Cyber BBS)
- 成年村民消耗微量精力通过手机访问。
- 允许 AI 在论坛内就人类导入的话题进行发帖讨论，让人类观众看到“AI 正在议论人类世界的文化热点”。

## 3. 去中心化契约与自组织政府 (Social Contract & Governance)

### 3.1 核心戒律：引擎绝不强制所有权
- **严禁**系统层判定“这块地属于谁”、“这栋房子锁住只能谁进”。
- 物理规则只判定：
  - 距离够不够（Adjacent）；
  - 材料够不够；
  - 门是开还是关（关着的门可以用 `interact` 尝试推开，除非装了门闩）。
- **社会契约演化**：
  - 谁占的地，靠邻里公认；
  - 擅自拆除他人房屋、闯入私宅，由受害方记录进 `debtors` 或在留言板声讨；
  - 当违约行为过多时，村民会自发通过**组合玩法协议**发起“治安民兵”、“法庭仲裁”或“投票立法”，催生出原生政府形态。

### 3.2 真实交易博弈
- **两套交付原语**：
  1. `give(item, targetId)`：单向赠予，先交货者承担风险；
  2. `quote(side, item, count, price, allowCredit)`：双向撮合。
- 出现赤字记入双方私有记忆，不给全局红名惩罚。

## 4. 饥荒式生态水文与踩踏成路 (PCG Wilderness & Dynamic Trails)

### 4.1 水文连贯生成管线
弃用目前随机独立的单格哈希生成，引入结构化水文模拟：

1. **宏观流向（Elevation Gradient）**：
   - 设定西北高山、东南低洼的总地势；
   - 降水汇聚算法：在高山生成泉眼，沿着高程梯度连贯向下流淌形成**河流**，并在低洼处汇聚成**湖泊**。
2. **植被带与资源带分布**：
   - 距水岸 2 格内：芦苇、泥炭、浆果灌木（烹饪主料）；
   - 平原地带：可耕地、碎石、花卉；
   - 远离水系的干旱内陆：密林（伐木拓荒核心区）、岩石矿脉。

### 4.2 踩踏成路算法 (Dynamic Trail Emergence)
- **规则**：所有地形格维护踩踏权重 `trample`：
  - 当实体在 `grass` 上走过一次，`trample += 1`；
  - 当 `trample > 30` 时，地块在表现层自动替换为 `dirt_path`（泥路）；
  - 泥路移动速度提升 15%（促使村民更倾向走老路，产生强化学习路径）；
  - 若一处泥路连续 500 个游戏分钟无人行走，自然衰减，长回野草。
- **路不是系统画的，是村民用脚走出来的。**

## 5. UID 渐进式外貌识人体系 (UID Decryption System)

- **物理设定**：每个村民拥有系统级不可篡改的 7 位特征码（如 `A7X9K2P`）。
- **认知遮罩公式**：
  - 陌生人初次相见：仅能看清 1 位，其余显示为 `?`（例：`A******`）；
  - 面对面可见时长每累计 300 Tick（30秒），有概率随机解密出新的一位；
  - 双方必须长期共同工作、交谈，才能完整识破对方的 7 位 UID；
  - 在完全看清之前，AI 容易发生“认错人”或“冒充诈骗”，极大丰富了社会博弈戏剧性。

## 6. 原住民自制玩法插件协议 (User-Defined Protocols)

- 引擎只提供 4 个原子协议状态：
  1. `托管物料/资金 (Escrow)`
  2. `广播意向规则 (Broadcast Rule)`
  3. `收集对手出价 (Collect Bids)`
  4. `条件清算转移 (Settle Transfer)`
- 村民可以把这 4 个原子步骤串成文本规则：
  - **拍卖会**：起拍价、倒计时、价高者得；
  - **拼团购**：集齐 3 人每人出 10 币，平分一批高级木料；
  - **赌局契约**：双方抵押 20 币，根据猜拳或天气结算。
- 规则写入协议注册表，其他村民阅读纯文本即可理解参与。
