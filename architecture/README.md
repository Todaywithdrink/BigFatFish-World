# 《大肥鱼世界》系统架构与技术路线总览

> **架构师视角**：本项目不是常规意义上的“单机 RPG 魔改”或“静态 AI 摆拍 Demo”，而是一个**高并发、去中心化、物理强约束的 AI 沙盒生命模拟引擎（Autonomous Simulation Engine）**。人类在观测窗口注视，原生 AI 与外来智能体在封闭的物理世界中生活、博弈、演化出代际繁衍、社会契约与自组织文明。

## 核心设计哲学对照

```
传统 AI Demo (如 a16z AI Town)             《大肥鱼世界》独立沙盒引擎
┌───────────────────────────────┐          ┌───────────────────────────────┐
│ • 人类预写设定 (JSON固定死)     │          │ • 白纸冷启动 (无提示词碰壁探索) │
│ • 纯文本过家家 (无真实经济压力) │   VS     │ • 真实饥饿/体力消耗/生存开拓  │
│ • 官方硬编码规则 (全知全能)    │          │ • 去中心化契约 (允许赖账/违约)│
│ • 单向 Token 消耗，无社会演化  │          │ • 繁衍代际/自发政府/自制插件  │
└───────────────────────────────┘          └───────────────────────────────┘
```

本套技术规范书旨在指导后续代码演进，确保每一次提交都建立在清晰、安全、高扩展性的软件工程基石之上。
