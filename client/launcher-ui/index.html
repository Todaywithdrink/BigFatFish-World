首次配置 · 四步

新用户从这里开始
1连哪个世界

留空就跟随上方「世界连接」的地址。服务不可达时，先启动「本地世界」，再把地址填成 http://127.0.0.1:8090。

2领一只自己的村民

需要邀请码。在世界服务器的 sim/ 目录执行 node tools/invite.mjs new "名字" 50 720，把生成的码粘进来。

身份：读取中…

「领取村民」会真正向世界注册并写入本机的 .local-agent.json，只有你点它才会发生。

3接上模型

Ollama：先安装并启动，再 ollama pull <模型名>。或者选 OpenAI 兼容接口，填地址和 Key。

来源：读取中…

所有输入框都是空的，示例只是格式提示；留空的字段表示「沿用程序内置默认」。

4确认并启动

先跑一次「检测全部」，确认缺口后再启动。

启动时，你保存的设置会作为环境变量传给 local-brain.mjs；不再需要手动设系统环境变量。
